# fertility_preference_Indonesia
Welcome to the Research Analysis Repository! This repository contains R scripts used for conducting exploratory data analysis and performing panel data analysis related to our study on fertility preferences and household decision-making. The repository includes two key R code files:

1) code_eda.R - For exploratory data analysis.
2) code_analysis.R - For descriptive and panel data analysis.

The dataset used in this repository is sourced from the Indonesian Family Life Survey (IFLS), provided by RAND. We acknowledge RAND for their invaluable contribution in providing this comprehensive data. You can access the IFLS data [here](https://www.rand.org/well-being/social-and-behavioral-policy/data/FLS/IFLS/access.html).
